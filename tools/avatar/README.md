# Try-on model for the 3D demo

`public/demo/avatar.glb` is generated by these scripts from the MakeHuman base mesh,
targets, rig and weights (all released as CC0 by the MakeHuman project,
https://github.com/makehumancommunity/makehuman). Body shape, the relaxed arms-down pose,
the oversized tee, wide denim and chunky sneakers are all built here; no other assets are used.

    git clone --depth 1 https://github.com/makehumancommunity/makehuman /home/claude/makehumancommunity/makehuman
    python3 tools/avatar/build.py public/demo/avatar.glb
